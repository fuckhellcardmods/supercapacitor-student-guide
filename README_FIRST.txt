SUPERCAPACITOR STUDENT GUIDE — SHARING OPTIONS
================================================

RECOMMENDED: GITHUB PAGES
-------------------------
This folder is ready for GitHub Pages. The complete phone guide is contained
inside the single file named index.html.

1. Create a new PUBLIC GitHub repository, such as:
   supercapacitor-student-guide
2. Upload the CONTENTS of this folder to the repository.
   Do not upload only the ZIP file.
3. Confirm that index.html is visible at the top level of the repository.
4. Open repository Settings > Pages.
5. Under Build and deployment:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: /(root)
6. Save and wait for GitHub to show the published website URL.
7. Open that URL on a phone while signed out of GitHub.
8. Make a QR code that points to the published URL.

QUICK PDF-ONLY OPTION
---------------------
Upload Supercapacitor_Student_Guide_PDF_Backup.pdf to OneDrive or Google Drive.
Set access to Anyone with the link / Viewer. Use that sharing URL for the QR code.
This is easier, but the scrolling HTML webpage is better on phones.

ONE-DAY LOCAL BACKUP
--------------------
Double-click START_LOCAL_SERVER.bat.
Students must be on the same Wi-Fi as the host computer.
Use ipconfig to find the host computer's active Wi-Fi IPv4 address.
Their URL will be similar to:

    http://192.168.1.25:8000/

Important: school or guest Wi-Fi may block phone-to-computer connections. Test
this at the actual school before relying on it. Keep the PDF and printed copies
as backups.

DAY-OF RECOMMENDATION
---------------------
- Print one large QR code at the entrance.
- Put one smaller QR code at each workstation.
- Print the short URL beneath every QR code.
- Keep 2–3 printed copies of the guide.
- Test the QR on both an iPhone and Android phone before students arrive.
- Test while signed out of the hosting account.
